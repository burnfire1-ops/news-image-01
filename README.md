## How to run

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

This copies the image in this repo (`entry.png`) byte-for-byte to
`<output>/entry.png`. No network, no clock, no randomness; the output is
deterministic. Requires Node 22 (standard library only).
